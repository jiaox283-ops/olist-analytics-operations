## 2. 做法

对应 `src/03_customer_analysis.py`，按执行顺序：

### 2.1 样本筛选

1. 读订单级宽表 CSV，`order_id`、`customer_unique_id` 按字符串读入，断言 `order_id` 唯一
2. 解析购买时间，固定基准日 `2018-09-01`，购买时间上限取该日
3. 保留满足全部条件的订单：`order_status = 'delivered'`、购买时间早于基准日、购买时间非空、`customer_unique_id` 非空且非空白、`item_amount` 非空且 ≥ 0

得到 96,478 笔订单。客户一律用 `customer_unique_id` 统计，`customer_id` 是订单级的，同一人多次下单会得到不同值。

### 2.2 打四个有效标记

调用 `src/analysis_contract.py` 的四个函数，返回的是 Series（无效位置为 NaN）而不是布尔掩码：

| 函数 | 条件 | 用于 |
|---|---|---|
| `valid_review` | 已送达、`flag_no_valid_review = 0`、评分在 1–5 | 评价均分、低评分率 |
| `low_review` | 有效评分 ≤ 2 | 低评分率分子 |
| `valid_delay` | 已送达、`usable_delay_label = 1`、`is_delayed ∈ {0,1}` | 延迟率 |
| `valid_duration` | 已送达、`usable_delivery_duration = 1`、配送天数 ≥ 0 | 平均配送天数 |

四个指标的有效分母分别计算，不共用。

### 2.3 R / F / M

按 `customer_unique_id` 聚合：

- R = 基准日 − 末次购买日（自然日数）
- F = `nunique(order_id)`
- M = `sum(item_amount)`

打分规则：

| 维度 | 切分 |
|---|---|
| R | ≤ 90 天 = 3；91–180 天 = 2；> 180 天 = 1 |
| F | 1 单 = 1；2 单 = 2；≥ 3 单 = 3 |
| M | 按三分位切，阈值 58.90 / 127.90 |

F 按实际笔数硬切，不按分位——F 的分布里 97% 是 1 单，分位切会把同样买 1 单的客户分到不同组。M 用分位切，相同金额保持同分。

### 2.4 六分层

用 `np.select` 按顺序判断，命中即停：

1. F ≥ 2 且 R ≤ 90 → 近期复购
2. F ≥ 2 → 较久未购复购
3. F = 1 且 R ≤ 90 且 M 评分 = 3 → 近期高金额单购
4. F = 1 且 R ≤ 90 → 近期普通单购
5. F = 1 且 R ≤ 180 → 中期未购单购
6. 其余 → 较久未购单购

把客群标签 merge 回订单表（`many_to_one` 校验），再分别按客群汇总客户数、金额、复购率与体验指标。

### 2.5 Cohort

1. 每个客户的入组月 = 其已送达订单中最早的购买月（在**全样本**内计算，2016 年就买过的客户不会被算成 2017 年新客）
2. `age` = 当前购买月 − 入组月
3. 按 (入组月, age) 统计去重客户数，`unstack` 成矩阵
4. 重索引到 2017-01 至 2018-08 共 20 个入组月 × 0–19 个观察月
5. 每个入组月只在已到达的观察月内填 0，未到达的留空
6. 逐行除以入组客户数，得到比例矩阵

M0 恒为 100%，后续月份是当月复购比例，不是累计复购率。热力图色阶上限压到 1%，否则低复购差异看不出来。

### 2.6 统一 90 天复购率

全期复购率（3.00%）混了不同观察长度，早期客户天然有更长的复购机会。为了让时间窗一致：

1. 取首次购买日 ≤ 基准日 − 90 天的客户（75,878 名）
2. 在这批客户中，找首次购买日之后、首次购买日 + 90 天之前有再次购买的（同日多单不计）
3. 得到 981 名，1.29%

### 2.7 Wilson 区间

延迟/按时两组的低评分率用 Wilson 95% 区间，不用正态近似（小样本比例接近 0 或 1 时正态区间会越界）。区间是订单层面的，未校正同一客户多单的相关性。

### 2.8 输出与校验

写出 7 个 CSV 加 1 个校验 JSON：客户明细、客群画像、购买频次、Cohort 人数/比例/分母、履约体验对比。JSON 里记录输入行数、分析行数、金额差、客群订单数加总差、两个 M 阈值、90 天口径的分子分母。脚本内断言金额差 < 0.01、客群订单数加总差 = 0。

## 3. 局限

1. 六分层的复购率是 100% 和 0%，由分组定义决定，不能作为分层具备预测能力的证据。
2. 客群之间的体验差异同时绑定了购买时期，不能解释为客户价值导致的体验差异。
3. 履约状态与评价是关联关系，未控制地区、商品、卖家、购买月份；部分评价可能早于最终送达。
